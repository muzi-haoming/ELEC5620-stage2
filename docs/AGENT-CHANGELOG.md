## 工具选择输出截断修复（本轮后续更新）

实际运行记录显示价格与物流工具选择均出现 `ModelOutputTruncated`。共同原因是工具选择调用固定使用 384 tokens，覆盖了默认预算。

| 修改项 | 修改前 | 修改后 |
|---|---|---|
| 工具选择输出预算 | 固定 384 tokens | 读取 `MODEL_MAX_OUTPUT_TOKENS`，当前默认及实测值为 2048 |
| 返回约束 | 简短理由 | 明确只返回 tool/reason JSON，理由最多 40 个中文字符的简短操作目的 |
| 业务及错误处理 | 原有校验、事务、截断拦截 | 保留，不把不完整响应当成功 |

验证：22 项自主 Agent 隔离测试通过，包括新增配置预算回归。真实 campus-qwen 配合隔离数据完成价格工具选择 2 次（query_market → use_market_price）及物流工具选择 4 次（read_order → read_property → read_event → prepare_delivery_update），均成功。未修改真实订单或业务数据库。真实市场来源检索不属于该次截断修复验证。

需重启后端使设置生效。AI 新品价格估算的独立 512 tokens 上限本轮未改。
